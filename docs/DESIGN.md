# 拾遗 · Collected Wonders — 创意站点集

> 总体设计文档 · 2026-08-21 · 零依赖纯原生 HTML/CSS/JS · 中英双语 · 5 + 1 冲刺

## 约定

- 每个作品独立文件夹，根目录 `index.html` 为门户（序 · GALLERY）
- 纯原生实现，无任何外部依赖（无 CDN、无字体文件、无图片资源），双击 `index.html` 即可运行
- 双语：每站右上角 中/EN 切换，localStorage 记忆偏好，默认跟随浏览器语言
- 完成定义：功能完整 + 无头截图自查渲染 + web-design-guidelines 审查通过 + git 提交

## 作品清单

### 1. 墨 · INK — 水墨流体画室 `ink/`
- **方向**：单点技术极致 + 视觉互动实验
- **核心**：WebGL2 手写 Stable Fluids 求解器（advection → divergence → pressure Jacobi → gradient subtract → vorticity confinement），墨色染料随速度场扩散
- **美学差异化**：主流流体模拟是霓虹彩虹风；本作做水墨——墨色（黑+靛青微变体）晕染在程序化宣纸纹理上，留白构图
- **功能**：笔锋（鼠标速度→力度）、笔宽/墨浓调节、洗纸（清屏带水洗动画）、朱红印章落款、导出 PNG（纸+墨合成）、自动演示（idle 时墨滴自落）
- **验收**：60fps 流畅、导出图片可直接当壁纸

### 2. 回声 · ECHO — 回声定位迷宫 `echo/`
- **方向**：叙事/游戏体验
- **核心机制**：全黑暗迷宫，点击发出声波涟漪，涟漪传播途中短暂照亮所触墙壁；玩家凭空间记忆导航至出口
- **系统**：5+ 关卡（格线数据 + 移动障碍）、步数统计与评级、剧情碎片（到达特殊格子解锁一句故事）、音效（WebAudio 合成回声声呐）
- **验收**：通关全部关卡无卡死、涟漪物理正确（圆形传播 + 衰减）

### 3. 造境 · SCAPE — 程序化声景 `scape/`
- **方向**：创意实用工具 + 视觉实验
- **核心**：所有声音由 WebAudio 数学合成（雨=滤波白噪声+随机雨滴脉冲、风=低频噪声LFO、篝火=布朗噪声+爆裂脉冲、雷=低频轰鸣包络），零音频文件
- **视觉**：程序化视差场景（远山剪影/雨幕/雪/星野），随天气与时刻参数无限生成
- **功能**：天气/时刻/强度三轴调节、专注计时器（番茄变体）、画面参数即听觉参数的统一模型
- **验收**：无爆音、参数连续可调、场景与声音联动一致

### 4. 纸间 · LETTERS — 互动书信 `letters/`
- **方向**：叙事体验
- **核心**：分支微小说《灯塔看守人》：拆开一封信→墨迹渐显阅读→文末做出选择→导向下一封信；多结局（≥4）
- **交互**：信封拆启动画、纸张质感、阅读进度墨迹显现、选择按钮即"回信"
- **内容**：原创双语全文（中英各一套完整叙事，非机翻腔）
- **验收**：全分支可达、结局统计页、重玩入口

### 5. 序 · GALLERY — 门户 `index.html`
- 生成艺术动态背景 + 作品预告卡（悬停预览动效）+ 单独打开每作的入口

### 6. 褶皱 · FOLD — 分形星球（冲刺彩蛋，时间富余才做）`fold/`
- WebGL 曼德博集合，双精度缩放至 ~10¹³，坐标 URL hash 分享，平滑迭代着色

## 执行顺序

INK → ECHO → SCAPE → LETTERS → GALLERY → (FOLD)，每完成一个 git commit 一次。
