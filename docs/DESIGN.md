# 拾遗 · Collected Wonders — 总体设计文档

> v3.0 · 2026-08-22 · 零依赖纯原生 HTML/CSS/JS · 中英双语 · 经 20 轮迭代
> 在线版：<https://jfg-jfg.github.io/collected-wonders/> · 源码：<https://github.com/jfg-jfg/collected-wonders>

## 约定

- 每个作品独立文件夹，根目录 `index.html` 为门户（序 · GALLERY）
- 纯原生实现：无构建、无框架、无 CDN、无图片资源；`file://` 双击即开
- 双语：每站 中/EN 切换，localStorage 记忆偏好，默认跟随浏览器
- 完成定义：功能完整 + 无头截图亲眼验证 + `tools/smoke-test.sh` 通过 + git 提交
- 无障碍基线：`prefers-reduced-motion` / `color-scheme` / `focus-visible` / `overscroll-behavior` / 375px 适配

## 作品与深度（至 v3.0）

### 1. 墨 · INK — 水墨流体画室 `ink/`
- **流体核心**：WebGL2 手写 Stable Fluids（advection / vorticity / Jacobi 压力 / 梯度减除）
- **笔刷系统**：圆笔（晕染）/ 硬笔（各向异性 2.4× 出锋）/ 泼墨（簇状洒点）/ 水笔（负墨破墨）；笔速映射浓淡（飞白）、压感、预览光标
- **墨色**：双通道染料（R 密度 / G 密度×色相）→ 玄墨/靛青/赭石/朱砂渐变混色
- **纸质**：生宣（涡度30 晕散）/ 熟宣（15 可控）/ 绢本（暖色丝纹）——改变流体参数与纹理
- **作品管理**：IndexedDB 自动续档 + 八页画册（缩略图/载入/撕页）+ 长卷导出 + 题款装裱（干支年/朱印/双线画框）+ 2048 PNG
- **氛围**：闲时自动画笔（正弦弧线演示）、洗纸动画、印章随墨色换印泥

### 2. 回声 · ECHO — 回声定位迷宫 `echo/`
- **核心机制**：声呐涟漪照亮扫过的墙（亮度指数衰减），凭空间记忆导航
- **关卡体系**：六层主线（种子化生成：递归回溯 + 编织环路 + 巨殿柱厅，BFS 双重校验）→ 无尽下潜（尺寸/游魂递增）→ 每日深潜（日期种子）→ **名井集**（精选三井，奖杯纪录）→ **造井编辑器**（五工具 / 实时校验 / Base64 关卡码分享）
- **挑战层**：游魂（随机游走 + 20% 追猎偏置，触碰迷失）、余像辅助模式、照亮率、通关热力回放、11 成就墙、计时与最佳纪录

### 3. 造境 · SCAPE — 程序化声景 `scape/`
- **声引擎**：九声道纯数学合成（零采样）：雨/风/篝火/溪流/夜虫/雷/鸟鸣(日间FM)/远钟/雪耦合视觉
- **三主题**：⛰山（三层视差山脊）/ 🌊海（倒影+日月烁光带+微波）/ 🏙城（天际线夜窗+航空障碍灯）
- **氛围系统**：时刻 0-24h 驱动天色/日月/星、季节花瓣（春樱/秋枫）、彩虹/流星/极光彩蛋、时光流转（4 分钟昼夜）
- **工具性**：自定义境×6、睡眠渐弱、专注计时、随机造境、音画录制 webm、后台保活

### 4. 纸间 · LETTERS — 互动书信《守灯人》 `letters/`
- **叙事**：十三封信双语分支剧本（1989 风暴夜之谜），4 结局（含隐藏"第十三封信"——空信封）
- **深度**：陈潮生明信片(1991)/奶奶未寄出的回信(1976)两封支线信、信笺横格、年代 sepia、结局 SVG 小景、信堆图鉴（已读重读联动）、进度金线

### 5. 褶皱 · FOLD — 分形星球 `fold/`
- **精度**：df64 双单算术（Dekker/Knuth）曼德博/儒利亚集合，缩放至 10¹³
- **体验**：平滑惯性缩放（target/view 指数逼近）、七地名巡航 + 自定义书签✚、四调色板、PNG 存图、URL 坐标分享、待机深潜、交互期降迭代提速

### 6. 序 · GALLERY — 门户 `index.html`
- 流场粒子生成背景 + 五卡阶梯入场 + 各卡主题色徽记动画 + 跨站统计行 + 在线/源码链接

## 工程基建

- `tools/smoke-test.sh`：无头 Edge 六站 JS 错误回归（当前 6/6）
- `tools/gen-wells.mjs`：名井关卡码生成器（与游戏内生成器同源逻辑）
- 测试直达 hash：`echo#lvN/#edit[=码]` · `scape#snow=.9&time=23&theme=N` · `letters#nN` · `fold#julia,cx,cy`
- 质量事故档案：着色器 varying 未声明 / 手作迷宫不可达→生成器化 / 碎片索引错位 / bak 恢复链覆盖未提交代码（教训：**先提交再折腾**）
