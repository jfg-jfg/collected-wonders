# 真机验收清单 · DEVICE CHECK

> 无头验证全部绿 ≠ 真机没问题。iOS Safari / 安卓 Chrome 各过一遍，每站 3 分钟。
> 发现问题直接把"哪一站 + 哪一步 + 什么现象"丢回给开发流程即可。

## 通用（每站）
- [ ] 首屏 3 秒内出现（本地 file:// 与在线版各试一次）
- [ ] 竖屏不横向滚动、不裁字；横屏工具栏/面板不盖死内容
- [ ] 中文/EN 切换正常（在线版可用 `#lang=en` 直达英文）
- [ ] 音频：首次点击后有声；静音开关有效

## 墨 · INK
- [ ] 手指画：慢划浓、快划飞白
- [ ] 双指捏合进纸面检视，滚轮…改：双指缩放/拖移正常
- [ ] 「极速」开关切换后流畅度可感知改善
- [ ] 存画 → 画册 → 重新载入
- [ ] 上传印章图片（拍照或相册）

## 回声 · ECHO
- [ ] 按住拖动连续走（拖行连走），单点发声呐
- [ ] 完成第一层；菜单 12 层卡片 + ∞ 无尽 + 6 口名井可点
- [ ] 造井：画墙 → 试玩 → 「回廊」返回编辑器（草稿还在）
- [ ] 通关卡片文字够大、小地图不挡路

## 造境 · SCAPE
- [ ] 滑杆调雨/篝火/夜虫有声；心境随机 + toast
- [ ] 时光流转开 → 天色连续变化
- [ ] 分享 → 复制链接 → 另一设备/无痕窗口打开复现同一场景（`#w=`）
- [ ] ☾ 睡眠定时 15 分（可不等完，确认按钮态变化即可）
- [ ] ● 录 10 秒停止 → 下载的 webm/mp4 能播

## 纸间 · LETTERS
- [ ] 拆信动画 → 逐段显影 → 点信纸跳过
- [ ] 读完一封信用左上「← 信箱」返回，进度保留（继续读信可进）
- [ ] 信堆重读 → 左上「← 信堆」退出无死路
- [ ] 让 AI 写一个 → 复制提示词 → 粘回导入（可用任意 AI 试一轮）
- [ ] 手写故事：加一封信两个选项 → 试读 → 保存到信箱

## 褶皱 · FOLD
- [ ] 双指缩放深潜：10⁸ 不糊；深潜过 10¹³ 后画面仍稳定（微扰档）
- [ ] ▶ 巡航：扫掠→锁定→深潜→抵达低语四段完整
- [ ] ☄ 今日：点击出行 → 提示语 → 抵达盖戳 ✓
- [ ] ◈ 航志：某处停留 3 秒后入志，面板回访能飞回原地
- [ ] 寄 出：明信片含邮票/邮戳/题款/朱印，下载可看
- [ ] ♪ 声：drone 与计数脉冲随深度变稀
- [ ] 缩放瞬间有径向拖影（拉丝），静止后锐利
- [ ] G 键 / #grid=1：三分+黄金分割网格叠显
- [ ] 触底（10¹³）一次出现「灯还亮着」；此后造境夜海灯塔常明（跨站联动）
