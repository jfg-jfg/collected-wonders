# 拾遗 · 共享宇宙年表 · THE SHARED UNIVERSE

> 五件作品共享同一个世界。这是一份给读者（与未来的写作者）的年表。
> 核心母题：**灯**——所有故事最终都回到一盏还亮着的灯。

## 年表（按故事内时间）

### 1962–1989 · 白鹤礁灯塔
- **1962** 周远上岛守灯（《守灯人》）。妻子林素秋在窗台点灯，一别三十年。
- **1975** 素秋携子渡海探望，风浪不得靠岸——灯塔下最亮的四分钟，也是最暗的。
- **1989.10.4 夜** 油路堵塞，灯灭四分钟；渔船**拾遗号**触礁。
  - 守灯人提马灯下机房排除油路，灯复明；
  - 再入海救人：十九岁水手**陈潮生**被他推上礁石得救；
  - 无名杂役**李长庚**（以长庚星为记）摸黑凫水，托住了另一只手；
  - 周远与李长庚殁于海。保险结案归咎"守灯人擅离职守"，证词下半页被撕。
- **1989.11** 陈潮生借走那半页证词，没有归还。此后每年清明向灯塔寄一张明信片，收信人写：**灯**。

### 1999–2000 · 鹊山观星台
- **1999 秋** 彗星 C/1999 Y2 过境。观测员**沈青梧**算出周期 27.4 年：2026 年 4 月回归。
  同事陈砚秋离开，台里只留她与一盏红灯（电池 1998 年出厂）。
- **2000 元月** 交台。移交清单写明：红灯不列入移交——"一个台，总得有点一直开着的东西"。
- **2007** 沈青梧视力衰退，预先写下一封信，托山下保管处代存：等彗星回来那天，交给当班的人。

### 2018–2026 · 停钟巷 / 雪国 / 深海（与主线平行的三段往事）
- **停钟巷**：修表匠沈师傅在心疾之夜后，把整条巷子的钟停在 4:44，独留亡妻的怀表行走。
- **雪国列车员**：一封迟到三十年的调令，与一个冬天没能寄出的往返信。
- **深海电台**：4021 千赫，停机前最后一夜，不该存在的信号。

### 2026 · 收束之年
- **三月** 阿澄上鹊山清点观星台，发现未寄出的信与那盏没关过的红灯。
- **四月 11 日** 彗星如约回归。守夜者收到 2007 年的代存信——「灯还亮着，就轮得到有人看」。
- **夏** 白鹤礁灯塔拆除；**十月 4 日** 沉船存物柜起获入库：
  档案员补全拾遗号名册第七行（李长庚），陈潮生归还半页证词——
  浪里那盏移动的灯，终于写进了公家的纸里。

### 时间之外 · 沉没之城与褶皱星球
- **回声 · ECHO**：那座沉入水下的城。守灯人的日记仍在城里，一层一层，
  与无数口井、三种游魂、以及每天换一个的迷宫同在。登塔的尽头是天光。
- **褶皱 · FOLD**：一颗无限深的星球。触到 10¹³ 之下的人会看到一句话——
  「灯还亮着。不知道是谁在添油。」
- **造境 · SCAPE**：若有人在褶皱星球触底，造境夜海里的那座灯塔，就会一直亮着。

## 灯的谱系

| 灯 | 所在 | 状态 |
|---|---|---|
| 白鹤礁灯塔 | 守灯人 / 回声 / 拾遗号 | 灯的意义完成了（2026 拆除） |
| 马灯 | 周远手中 | 那晚在浪里亮了很久 |
| 观星台红灯 | 观星台 | 1998 年的电池，至今未关 |
| 布谷鸟钟 | 停钟巷 | 撬开小门那天，它自己醒了 |
| 深海电台 | 4021 kHz | 最后一夜之后，仍有信号 |
| 造境灯塔 | 造境·夜海 | 触底者令其常明 |
| 褶皱之灯 | 10¹³ 之下 | 还亮着。不知是谁在添油 |

> 写作约定（给未来的故事）：
> 1. 每个故事独立可读，互文只做彩蛋，不做门槛；
> 2. 「灯还亮着」是宇宙的收束句，不轻易使用；
> 3. 无名者的名字，值得专门写一个故事去找回。
