# 真机验收清单 · DEVICE CHECK

> 无头验证全部绿 ≠ 真机没问题。iOS Safari / 安卓 Chrome 各过一遍，每站 3 分钟。
> 发现问题直接把"哪一站 + 哪一步 + 什么现象"丢回给开发流程即可。

## 通用（每站）
- [ ] 首屏 3 秒内出现（本地 file:// 与在线版各试一次）
- [ ] 竖屏不横向滚动、不裁字；横屏工具栏/面板不盖死内容
- [ ] 中文/EN 切换正常（在线版可用 `#lang=en` 直达英文）
- [ ] 音频：首次点击后有声；静音开关有效

## 墨 · INK
- [ ] 手指画：慢划浓、快划飞白；飞白呈丝缕状（沿运笔方向连贯留白）
- [ ] 提按笔锋：同一直线上轻重/快慢有粗细变化，起笔渐细
- [ ] 湿边：落笔后一两秒内笔迹边缘略深、浓处见纸纹颗粒，随后干固定格
- [ ] 悬停滴墨：按住不动，墨滴缓缓积聚变大（水笔按住=持续化墨）
- [ ] 三种纸质手感不同：生宣顺滑易晕、熟宣涩、绢本居中
- [ ] 双指捏合进纸面检视，滚轮…改：双指缩放/拖移正常
- [ ] 「极速」开关切换后流畅度可感知改善
- [ ] 极速开 → 存画 → 极速关 → 载入存档：画面无错位花纹
- [ ] 存画 → 画册 → 重新载入
- [ ] 上传印章图片（拍照或相册）
- [ ] 自定墨色：长按任意色点 ~0.5s 弹取色器 → 换色后立刻用该色画（混色过渡用新色）；刷新后仍在

## 回声 · ECHO
- [ ] 按住拖动连续走（拖行连走），单点发声呐
- [ ] 完成第一层；菜单 12 层卡片 + ∞ 无尽 + 6 口名井可点
- [ ] 游魂三型：第 2 层起红色趋声魂（循声）、第 4 层加蓝游荡魂（不理声）、第 6 层加金守灯魂（守碎片，带金色巡界圈）；首遇有介绍卡
- [ ] 关卡卡编号：主线 1-12 显示「X / 十二」（EN 为罗马数字）；无尽第 1 层显示「∞ 1」
- [ ] 无尽模式越深越难：游魂变多、走得更快、回光熄得更快
- [ ] 名井带游魂的：被撞后游魂重生（不再消失）
- [ ] 空格长按只发一声声呐；**长按 ≥0.3s 松开 = 蓄力声呐**（蓝白收紧环、声浪更远、音更低沉）——之后几秒游魂会朝声源加速
- [ ] 钥匙与锁：第 10/11/12 层与无尽每 5 层，HUD 显示 🔒；找到 🗝（金色闪烁）后变 🔑，撞锁门有闷响+日记提示
- [ ] 造井：画墙 → 试玩 → 「回廊」返回编辑器（草稿还在）
- [ ] 通关卡片文字够大、小地图不挡路
