# 拾遗 · Collected Wonders

> 五件小小的奇物 · Five small wonders
> 零依赖 · 纯原生 HTML/CSS/JS · 双击即开 · 中英双语

一批以"创意网站"为载体的独立小作品。没有构建步骤、没有框架、没有 CDN、没有图片资源——每个作品都是一个自包含的 HTML 文件，双击即可在浏览器中运行。

**入口**：打开 `index.html`（序 · GALLERY 作品门户）

## 设计原则

- **零依赖**：不依赖任何外部资源，离线可用，`file://` 协议直接运行
- **单文件**：每个作品一个 `index.html`，样式、脚本、数据全内联
- **双语**：全站中/EN 切换，localStorage 记忆偏好
- **自验证**：迷宫关卡内建 BFS 连通性自检；无头浏览器截图验证渲染
- **各自的视觉个性**：五站五种美学，门户统一串联

## 快捷键速查

- **墨**：`W` 洗纸 · `S` 保存 PNG · 拖动作画（速度控制浓淡）
- **回声**：方向键/WASD 移动 · 空格/点击发声呐 · `#lv0`~`#lv5` 直达关卡
- **造境**：滑杆调声画 · 点击计时器循环 25/45/60 分钟专注
- **纸间**：点击拆信 · 选择回信推进剧情
- **褶皱**：滚轮缩放 · 拖拽巡游 · 双击俯冲 · 地名芯片巡航飞行
