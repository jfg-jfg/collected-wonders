# 拾遗 · Collected Wonders

> 五件小小的奇物 · Five small wonders
> 零依赖 · 纯原生 HTML/CSS/JS · 双击即开 · 中英双语

一批以"创意网站"为载体的独立小作品。没有构建步骤、没有框架、没有 CDN、没有图片资源——每个作品都是一个自包含的 HTML 文件，双击即可在浏览器中运行。

**入口**：打开 `index.html`（序 · GALLERY 作品门户，含跨站使用统计）

## 技术核心

- **墨**：WebGL2 手写 Stable Fluids 求解器（advection / vorticity / Jacobi 压力迭代），双通道染料实现墨色混合，`gl.blitFramebuffer` 撤销栈
- **回声**：声呐涟漪照明系统、种子化迷宫生成器（递归回溯 + 编织环路 + BFS 校验）、WebAudio 全合成音效
- **造境**：八声道纯数学合成（零采样），时刻参数统一驱动天色与声音，三层视差场景
- **纸间**：原创双语分支剧本、信封 CSS 3D 动画、墨迹渐显阅读、结局图鉴
- **褶皱**：df64 双精度模拟（Dekker/Knuth 双单算术）曼德博/儒利亚集合，缩放至 10¹³

## 设计原则

- **零依赖**：不依赖任何外部资源，离线可用，`file://` 协议直接运行
- **单文件**：每个作品一个 `index.html`，样式、脚本、数据全内联
- **双语**：全站中/EN 切换，localStorage 记忆偏好
- **自验证**：迷宫关卡内建 BFS 连通性自检；无头浏览器截图验证渲染
- **无障碍**：全站 `prefers-reduced-motion` / `color-scheme` / `focus-visible` / `overscroll-behavior`
- **各自的视觉个性**：五站五种美学，门户统一串联并展示跨站统计

## 快捷键速查

- **墨**：`1-4` 笔刷 · `[ ]` 笔宽 · `Z` 撤销 · `C` 墨色 · `W` 洗纸 · `S` 保存
- **回声**：方向键/WASD 移动 · 空格/点击发声呐 · `#lv0`~`#lv5` 直达关卡

- **褶皱**：`+/-` 缩放 · 方向键平移 · `J` Julia · `P` 调色板 · `S` 存图
