## 约定

- 每个作品独立文件夹，根目录 `index.html` 为门户（序 · GALLERY）
- 纯原生实现：无构建、无框架、无 CDN、无图片资源（favicon 亦为内联 SVG data-URI）；`file://` 双击即开
- 双语：每站 中/EN 切换，localStorage 记忆偏好，默认跟随浏览器
- 完成定义：功能完整 + 无头截图亲眼验证 + `tools/` 验证器全绿 + git 提交
- 无障碍基线：`prefers-reduced-motion` / `color-scheme` / `focus-visible` / `overscroll-behavior` / 375px 适配
- **共享宇宙**：回声（沉没之城 · 守灯人日记）与纸间《守灯人》（白鹤礁 · 周远）为同一座灯塔的两段叙事；回声登塔终章的碎片与纸间的关键物互文（四分钟 / 马灯 / 点灯一次）

## 作品与深度

### 1. 墨 · INK — 水墨流体画室 `ink/`
- **流体核心**：WebGL2 手写 Stable Fluids（advection / vorticity / Jacobi 压力 / 梯度减除）；动态三档画质（依帧率自适应 PRESSURE_ITERS/SIM_RES/涡度开关）
- **笔刷系统**：圆笔（晕染）/ 硬笔（各向异性 2.4× 出锋）/ 泼墨（簇状洒点）/ 水笔（负墨破墨）；笔速映射浓淡（飞白）、压感、预览光标；发丝级最小笔宽
- **墨色**：双通道染料（R 密度 / G 密度×色相）→ 八色墨渐变混色
- **纸质**：生宣 / 熟宣 / 绢本——改变流体参数与纹理；纸面检视（滚轮缩放 / 拖移，画布外为环境而非空白）
- **作品管理**：IndexedDB 自动续档 + 八页画册（缩略图/载入/撕页）+ 长卷导出 + 题款装裱（干支年/朱印/双线画框）+ 印面图片上传 + 2048 PNG

### 2. 回声 · ECHO — 回声定位迷宫 `echo/`
- **核心机制**：声呐涟漪照亮扫过的墙（亮度指数衰减），凭空间记忆导航；碎片台词 = 守灯人日记
- **关卡体系**：**十二层主线**（六风格加法式生成器：柱阵/梳齿/蜂巢/迷津/螺旋/沉街——开放底图+战略置墙，每关 20 次种子重试直至过 BFS 结构验证；路径下限 12）→ **登塔终章**（十 灯室 / 十一 油路 / 十二 天光，游魂增至 4 只）→ 无尽下潜（通关「九 · 门」解锁）→ 每日深潜（日期种子）→ 名井集 → 造井编辑器（自定义尺寸/碎片台词/Base64 关卡码）
- **游魂 AI v3**：BFS 最短路集合判定「玩家必经格」永不驻留 + 评分走位（趋声、壁龛不入、起点保护）——可声东击西
- **挑战层**：余像/尾迹辅助、近距低鸣、照亮率、通关热力回放、11 成就墙、计时与最佳纪录、小地图

### 3. 造境 · SCAPE — 程序化声景 `scape/`
- **声引擎**：十声道纯数学合成（零采样）：雨/风/篝火/溪流/夜虫/雷/鸟鸣/远钟/雪/落花 + **环境音乐层**（三套五声音阶×声道调制旋律生成）
- **六主题**：⛰山（远寺敲钟）/ 🌊海（灯塔光路）/ 🏙城（夜窗）/ **❄雪原**（枯枝林+积雪+月影+雪漂）/ **🏜大漠**（沙丘+热浪+岩石+星）/ **🛸太空舱**（舷窗+地球弧线+大气辉光+尘埃）
- **季节自动**：首访按月份选主题（冬→雪原 / 春秋→山 / 夏→海）
- **主题过渡动画**：切换时快照旧帧渐隐交叉淡化（0.6s）
- **昼夜系统**：SKY 关键帧插值（含日光系数 L）+ 日月轨道 + 月相 + 海面光路反光柱
- **联动彩蛋**：萤火/飞鸟/闪电/流星/极光/太阳雨彩虹（随声道与时辰联动）
- **工具性**：时光流转、心境随机×10、9 预设、`#w=` 分享链接、webm/mp4 录制、睡眠定时、每日气象、声道 LED、键盘快捷键（1-9/T/M/F/R/←→）、状态持久化

### 4. 纸间 · LETTERS — 互动书信 `letters/`
- **叙事**：四个双语故事包——守灯人（12 信 4 结局·隐藏「第十三封信」）/ 雪国列车员（8 信 4 结局·楷体蓝笺）/ 深海电台（8 信 4 结局·暗纸青字）/ **停钟巷（8 信 4 结局·隶书铜笺·隐藏「拨回来的一分钟」）**
- **引擎**：分支书信图（replies + contTo + 隐藏结局 require→replace）；per-story 字体/纸色/印章色；age 泛黄叠层；postcard 邮票角标；WebAudio 纸声（拆封火漆裂/展信/轻叩/结局双音钟）
- **创作工具链**：AI 提示词生成器（题材/信数/结局数/笔调/通信关系）→ 导入校验（结构/悬挂引用/```json 剥离/文件读取）→ 手写编辑器（节点式回信分支/四纸笔预设/试读/改编内置故事/edKey 幂等保存）→ 分享（直达链接/JSON）
- **进度**：信堆重读（reread 冻结回信）、结局图鉴点（悬停显名）、跨站统计

### 5. 褶皱 · FOLD — 分形星球 `fold/`
- **四模式**：曼德博 / 儒利亚 / 燃烧之舰 / **牛顿引力盆**（z³-1=0，三根色相+收敛速度亮度，128 迭代）
- **精度三级**：float（<3e4 提速）→ 修复版 df64（Dekker，至 3e12）→ **perturbation**（JS BigInt 定点参考轨道→RGBA32F 纹理，GPU float32 δ 重放，Pauldelbrot glitch 判定），下限 **10²⁰**；坐标全链 double-double（31 位），分享链接带 dd 低位
- **渲染**：三遍架构（迭代写 16F FBO → 着色 → 拉丝反馈）；DE 褶皱墨线、条纹平均织物、地质层调色（深度=地层）
- **叙事玩法**：纪元量化格命名、深度手记徽章、每日星球（日期种子+邮戳）、航行日志（缩略+回访+导出+**漂流瓶导入**+**倒航仪式 60s**）、叙事巡航（扫掠→锁定→深潜→纪元低语+黄金偏置）、明信片导出、计数音景、深潜拉丝、构图网格、待机守夜、触底「灯还亮着」
- **体验**：平滑惯性缩放、密度巡航、五调色板色相缓移、待机深潜（牛顿模式禁用）、书签、空闲补帧

### 6. 序 · GALLERY — 门户 `index.html`
- 流场粒子生成背景 + 五卡阶梯入场 + 各卡主题色徽记动画 + 跨站统计行（信箱统计按 letters-save-* 聚合）+ 键盘导航（←→ Enter）+ 在线/源码链接

## 工程基建

- `tools/smoke-test.sh`：无头 Edge 六站 JS 错误回归（`--dump-dom` 执行 JS，各站 window.onerror 将错误写入 DOM 供捕获；当前 6/6）
- `tools/validate-levels.mjs`：从 echo 提取生成器复验十二关 + 40 样本随机压力
- `tools/validate-stories.mjs`：故事包图验证（order/回信/contTo 悬挂、双语文本、隐藏结局、可达性）——首跑即捕获守灯人六级孤儿信链
- `tools/gen-wells.mjs`：名井关卡码生成器
- 测试直达 hash：`echo#lv0..#lvN(N≥12 无尽)/#edit[=码]/#dbg=daily` · `scape#w=<base64>` · `letters#p=<id>[&n=<节点>]`（`#dbg=editor/ai/import/stack/share`）· `fold#x=,y=,s=/#julia,cx,cy/#dbg` · `ink#bench/#dbg=album` · 全站 `#lang=en|zh` 语言直达
- 质量事故档案：着色器 varying 未声明 / 手作迷宫不可达→生成器化 / **1500 行静默 JS 错误致整站失效→从零重建+错误上报钩子** / v5 重建丢特性（录制/定时/彩蛋→v6 找回） / nextAfter 使 n2 链孤儿化→contTo / TDZ（resize 提前调 initParticles）/ bak 恢复链覆盖未提交代码（教训：**先提交再折腾**）
